# Simon Game 🎮

A simple **Simon Game** built using **HTML, CSS, and JavaScript**.  
Follow the sequence of colors and test your memory skills!

---

## Live Demo 🌐

Play the game here: [Simon Game Live](https://MMuusskkaann.github.io/simon-game/)

---

## Features ✨

- Random color sequence generation
- Level-based gameplay
- User input tracking
- High score saved in **localStorage**
- Responsive UI for desktop and mobile

---

## How to Play 🕹️

1. Press any key to start the game.
2. Watch the color sequence generated by the game.
3. Click the colors in the **same order**.
4. If you make a mistake, the game restarts.
5. Try to beat your high score!
